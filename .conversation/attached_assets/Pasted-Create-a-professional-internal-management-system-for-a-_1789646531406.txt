Create a professional internal management system for a private hospital called "Sanatorio del Salvador".

Project name: Sanatorio Salvador - Sistema Interno

Language of the entire interface: Spanish (Argentina)

Tech preferences:

Modern React + TypeScript + Tailwind CSS

Clean and professional medical/administrative design (soft blues, whites, grays, clean typography)

Responsive (desktop-first, good on tablet)

Use Supabase as backend (authentication + PostgreSQL database)

Sidebar navigation

Role-based access control

Main Structure
Create a modern sidebar with the following modules:

Dashboard (home)

Administración

Liquidación

Guardias

Inventario

Instructivos

Configuración (users, sectors, roles)

Authentication & Permissions
Login page with email + password

Users belong to one or more "Sectores" (sectors/areas of the hospital)

Roles:

Administrador General (full access)

Responsable de Sector (can only manage their own sector)

Usuario (limited view)

Important rules:

In Guardias and Inventario, users can only see and edit data from their assigned sectors.

Administrador General can see everything.

Modules detailed requirements
1. Dashboard

Summary cards: Upcoming reminders, pending guardias, low stock items, recent activity

Quick access to main actions

2. Administración (highest priority)

This module must include:

Agenda / Calendario de tareas

Ability to create events such as:

Generar cheques (example: from day 1 to 10 of the month)

Vencimientos

Tareas administrativas

Pagos

Each event has:

Title

Description

Due date

Type (cheque, vencimiento, tarea, otro)

Responsible person

Sector (optional)

Reminder system:

Automatic reminders that start notifying 2 days before the due date

Notifications visible in the system (bell icon)

List of upcoming reminders

3. Liquidación

Placeholder page for now

Message: "Módulo en desarrollo"

Keep the structure ready for future expansion

4. Guardias

Table/list of guardias by sector

Form to register a new guardia:

Sector

Date

Shift (Mañana / Tarde / Noche)

Professional name

Observations

Responsable de Sector can only create and view guardias of their own sector

Filter by date range and sector

5. Inventario

Inventory list filtered by sector

Each item has:

Name

Category

Current stock

Minimum stock

Unit

Sector

Last movement date

Ability to register stock movements (entry / exit)

Visual alert when stock is below minimum

Responsable de Sector only sees their sector inventory

6. Instructivos

List of instructivos grouped by sector/area

Ability to create/edit instructivos with:

Title

Sector

Content (rich text or markdown)

Version

Attachment (optional)

Search and filter by sector

7. Configuración

Manage Users

Manage Sectores

Assign users to sectors

Manage roles

Design requirements
Clean, professional, trustworthy medical/administrative aesthetic

Soft blue primary color (#2563eb or similar)

Good use of white space

Clear tables with filters and search

Toast notifications for success/error

Loading states

Empty states with helpful messages

Database
Create the necessary Supabase tables for:

users (linked to auth)

sectors

user_sectors

agenda_items

reminders

guardias

inventory_items

inventory_movements

instructivos

Include proper relationships and Row Level Security (RLS) policies so that users only see data from their sectors when applicable.

Extra

Dark mode optional (nice to have)
